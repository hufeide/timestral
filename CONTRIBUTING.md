# Contributing to timestral

Thank you for your interest in timestral. Please note that we do not accept pull requests.
Bug reports and questions are welcome as GitHub issues.

## Maintenance

timestral is maintained by the team at Mistral AI.

- We answer issues on a best-effort basis.
- We fix security vulnerabilities (CVEs) and major bugs.
- timestral has few runtime dependencies (torch, numpy, safetensors and huggingface_hub), so
  its exposure to security vulnerabilities is limited.
- If we stop maintaining timestral, we will archive the repository. It stays available read-only.

## How to report an issue

Open an issue on GitHub, and include as much detail as possible to help us reproduce the problem:

- A clear and descriptive title
- A minimal code example that reproduces the problem, with the shapes of the inputs
- The checkpoint you used, for example `mistralai/Timestral-209M`
- Expected and actual behavior, with any error message or stack trace
- Your environment: timestral version or commit, Python and torch versions, operating system,
  and CPU or GPU

## Security vulnerabilities

Please do not report security vulnerabilities in public issues. Report them privately to
[security@mistral.ai](mailto:security@mistral.ai).

Thank you for your understanding!
